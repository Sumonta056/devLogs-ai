The one controlled test: does size of task matter?

Mejba Ahmed ran 12 capped, fully automated Claude Code sessions — six with Superpowers, six without — on simple, medium and complex tasks. Overall the plugin was about 9% cheaper and used around 14% fewer tokens, but the average hides the real finding:

Simple tasks
More tokens

Planning a 50-line script with no ambiguity is pure overhead.

Medium tasks
Break-even

Similar cost, noticeably better-structured code.

Complex tasks
Savings

Planning prevented the expensive “built the wrong thing, restart” failure. Costs clustered 2–3× tighter.

Twelve sessions is directional, and the author bypassed the human-in-the-loop steps the plugin is designed around. Read the full write-up.
